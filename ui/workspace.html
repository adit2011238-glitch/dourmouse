Pinch a titlebar with one hand to drag it. Pinch with BOTH hands and change the distance between them to resize the focused window; change the angle between them to tilt it. Gated by the tray.py camera kill-switch — verified live-desktop, not this sandbox (see page source for the full honesty note). Raw landmarks are EMA-smoothed and pinch has real on/off hysteresis (see LANDMARK_SMOOTH_ALPHA / PINCH_ENGAGE_RATIO / PINCH_RELEASE_RATIO below) — SIGNAL above reports NOISY when smoothing is actively correcting a jittery frame. DELEGATE tries GPU first and falls back to CPU automatically (see startHandControl below) — an embedded desktop webview's GPU compute support is real but frequently degraded or absent compared to a normal browser tab, and MediaPipe's GPU delegate then either fails outright or silently produces near-zero real detections, which reads to a user as "hand tracking doesn't work" with no visible error at all.
