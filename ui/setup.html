DOURMOUSE

Welcome to Dourmouse

Dourmouse is an assistant that runs on your own machine. Before it can answer anything, it needs to know which intelligence to use.

You should know what it can reach. With your permission it can:

  • Read and write filesOnly the ones you point it at.
  • Run commandsOn this Mac, in the folders you allow.
  • Send mail as youOnly after you connect an account.

Anything destructive asks first, every time.

Choose a model

Local runs entirely on this machine and needs no key. The cloud option is faster and free to start.

  1. Open build.nvidia.com. It opens in your browser.
  2. Sign up with an email. No card is needed.
  3. Pick any model, then press Get API Key.
  4. Copy the whole key. It starts with nvapi-.
  5. Paste it below. We check it works before saving.

Connect Google

Optional. Sign in and Dourmouse can read and act on your Gmail, Calendar and Drive when you ask it to. Nothing is touched until you do. Skip this and use Dourmouse with no Google account at all; you can connect one later from Settings.

Google sign-in is not set up on this install. You can still use Dourmouse fully without it; it can be added later in Settings.
