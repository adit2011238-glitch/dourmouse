// STEPS

  1. On your Mac run
    python -m dourmouse.mobile_link
    (it prints the token + QR).
  2. Same Wi-Fi: open the LAN URL above — or scan its QR from the Camera app.
  3. Anywhere: install Tailscale on the phone, sign in to the same account as the Mac, open the TAILSCALE URL.
  4. Paste the token here to unlock — the session cookie sticks until you quit the browser.

// INSTALL AS AN APP (NO BROWSER CHROME)

DourMouse is an installable app — own icon on your home screen, full-screen window, no Safari/Chrome tabs.

  1. iPhone/iPad: while this page (or the unlocked app) is open, tap the Share button, then Add to Home Screen → Add. The DourMouse icon lands on your home screen; tapping it opens the app standalone.
  2. Android: open the menu (⋮) → Add to Home screen / Install app → Install.
  3. Open it like any app from your home screen — it stays connected whenever your Mac is running.
