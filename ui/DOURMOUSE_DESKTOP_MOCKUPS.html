TRAY MODE POLICY
· Off by default — closing the window quits (the honest default for a personal tool).
· Opt-in setting: "close to menu bar" keeps the core running (server + SSE + alert fan-out) with the window hidden.
· The tray icon shows the live alert count from the SSE hub.
· Low-CPU by design: the only background work is the existing env-gated live polls; no timers invented for the tray.
Battery honesty: tray mode is for users who want alerts while closed. It is never created silently.

TECHNOLOGY — EVIDENCE-BASED CHOICE

Recommendation: Option A — keep and harden the PyWebView native shell. See DESKTOP_DESIGN_PORTFOLIO.md §3 for the full reasoning.
CRITERIONPYWEBVIEW (A) — RECOMMENDEDELECTRON (B)TAURI (C)

Decisive fact: every subsystem is Python + plain HTML/JS already speaking 127.0.0.1:8765, and all tests are pytest. Porting the shell discards working, tested code for zero user-visible gain. Electron remains the documented fallback if update/packaging quality ever becomes the blocker — the core is portable.
