Windows will warn you the first time

This build is not code-signed yet, so Windows shows a blue "Windows protected your PC" screen. That is SmartScreen reacting to an unrecognised publisher, not a virus warning.

  1. Click More info
  2. Click Run anyway

Once per machine. If you would rather verify the file first, compare its checksum against the one below.

Install

  1. Run the installer. It installs for you only and never asks for administrator rights.
  2. On first launch, setup asks which intelligence to use.
  3. If you have Ollama installed it is detected automatically and works immediately — no key, no account, nothing leaves your machine.
  4. Otherwise setup walks you through getting a free NVIDIA key, step by step, and checks it works before saving.

Your settings are kept outside the app folder, so updating or reinstalling never wipes them.

Runs locally
Models run on your machine or your own hardware. Nothing is sent anywhere you did not configure.
Asks before it acts
It can read files, run commands and send mail. Anything destructive asks first, showing the exact action.
World monitor

Four interfaces
Pick the look on first run — amber console, light workspace, mono terminal, or gothic.
