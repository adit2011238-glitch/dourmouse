What is it

One directive box. A whole fleet of agents.

DOURMOUSE turns a single natural-language instruction into a coordinated run across dozens of purpose-built sub-agents — mail, web research, markets, code, browser automation, calendar, memory, music, and more — running entirely on your own hardware.

  • Local-first: no cloud brain, no account on someone else's platform.
  • Every action visible: plan steps, tool runs, results, and latency stream live.
  • Every risky action gated: sends, writes, and submissions wait for your approval.
The core loop

From directive to done, transparently

  • Plan — a deterministic planner ranks the roster and emits STEP 1/N → agent.
  • Execute — the orchestrator runs a tool loop: real tools, real results.
  • Stream — the task deck shows SEARCH / CODE / MAIL / DATA / REPLY as they happen.
  • Gate — confirmation-gated tools pause for a human approval card.
  • Finish — the reply lands with first-token timing; the session is stored.

If a step is genuinely impossible, the agent says so explicitly and finishes — it never fabricates a success.

Honesty contract

No fabricated results. Ever.

  • Missing config → NOT CONFIGURED with the exact fix.
  • Offline backend → the real error (e.g. Yahoo HTTP 429), local AI takes over.
  • An impossible step → explicitly said, then finish.
  • Every write is confirmation-gated; every read states its scope.
